1. The RAG Efficiency-Accuracy Dilemma

Failure Mode 1: Static Single-Pass RAG

Catastrophic Failure on Multi-Hop

  • Retrieves once, prepends context, and generates.
  • Cannot resolve entity bridges (e.g. "Did the director of Inception win an Oscar before Interstellar?").
  • Intermediate entities unknown upfront; context dilution triggers hallucinations.
Failure Mode 2: Unconditional Agentic RAG

Prohibitive Cloud Cost & Latency

  • Deploys multi-draft critique loops on every query.
  • Simple factual queries incur 10–15+ LLM calls.
  • Multi-second latency and extreme GPU token consumption make production impractical.

Research Question: Can an adaptive operating-system-inspired queue match exhaustive multi-hop accuracy while dynamically eliminating 50%+ of unnecessary LLM calls on simple queries?

2. Architecture: The MLFQ Paradigm

Mapping OS Multilevel Feedback Queues to Generative Retrieval

Level 0
Direct Parametric

3 direct samples ($T=0.7$). Zero retrieval tokens. Sub-second latency.

Exit: High S1
Level 1
Hybrid RAG

BM25 + Dense RRF fusion ($k=5$). Citations generation.

Exit: Relevant S2 & S3
Level 2
Iterative Multi-Hop

Sub-query decomposition planner + bridge chunk reranker.

Exit: Complete S4
Level 3
Agentic Synthesis

Broadened $k=10$, parallel drafting, critique-revise loops, voting.

Terminal Exit

Production Safety Safeguard: Hard Budget Guard enforces $C_{\max} \le 15$ cumulative calls. Graceful fallback on budget exhaustion.

3. The 4 Verification Signals (Reference-Free)

$S_1$: Parametric Self-Consistency

$$S_1 = \frac{\text{Count of Mode Normalized Answer}}{\text{Total Direct Samples } (N=3)} \in [0.33, 1.00]$$ Measures internal parametric stability before incurring index lookup costs.

$S_2$: Retrieval Relevance Grade

$$S_2 = \frac{\sum_{i=1}^k \mathbb{I}(\text{Document}_i \text{ contains relevant evidence})}{k} \in [0.00, 1.00]$$ Inspired by CRAG; audits what fraction of context contains actionable facts.

$S_3$: Claim-Level Groundedness

$$S_3 = \frac{\sum_{c \in \text{Claims}} \mathbb{I}(c \text{ is entailment-supported})}{|\text{Claims}|} \in [0.00, 1.00]$$ Deconstructs answer into atomic claims; prevents ungrounded hallucinations.

$S_4$: Multi-Hop Completeness

$$S_4 = \frac{\sum_{q \in \text{Plan}} \mathbb{I}(q \text{ is addressed in answer})}{|\text{Plan}|} \in [0.00, 1.00]$$ Confirms all decomposed bridge sub-questions are answered before exiting.

7. Quantitative Deficit Attribution (4.60 pts)

93% of Deficit: Level 0 Premature Exits

4.256 Points Accounted

$$\text{Penalty} = 19\% \times 22.4 = 4.256\text{ pts} \quad (92.8\%)$$ The Epistemic Blind Spot:
Self-consistency is a proxy for confidence, not truth. When an open-weight model holds an entrenched hallucination, all stochastic samples converge ($S_1=1.00$), triggering a false-positive exit.

7% of Deficit: Level 3 Agentic Degradation

0.332 Points Accounted

$$\text{Penalty} = 2\% \times 16.6 = 0.332\text{ pts} \quad (7.2\%)$$ Context Dilution Noise:
Injecting broadened context ($k=10$) into critique-revise prompts introduces distractor noise, degrading token F1 relative to targeted Level 2 hops.

$$\Delta \text{Gap}_{\text{Total}} = 4.256 + 0.332 = 4.588 \approx 4.60\text{ percentage points (100% accounted)}$$

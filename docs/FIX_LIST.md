## Rules for the agent
1. Work on a new branch from `feature/feedbackrag-turbo`.
2. For each item: (a) run the Verify step and paste the real output, (b) say whether the issue is confirmed, (c) fix, (d) rerun, (e) show the new output that meets the Acceptance criterion.

5. Never use the test split for tuning or training.
6. At the end, give a table: item ID, confirmed or not, what changed, evidence.
